let arr = [10, 20, 30, 40, 50];
let target = 40;
let low = 0, high = arr.length - 1;

while (low <= high) {
  let mid = Math.floor((low + high) / 2);
  if (arr[mid] === target) {
    console.log("Found at", mid);
    break;
  }
  arr[mid] < target ? low = mid + 1 : high = mid - 1;
}

Inside CodeLens AI Architecture

        

          CodeLens AI is a client-side program visualization and runtime analysis platform. It executes JavaScript in real-time via an in-browser Abstract Syntax Tree (AST) evaluator without using unsafe eval(), capturing deterministic memory snapshots, scope chains, and call stack frames at every single statement.

⚡ Key Engineering Highlights & Technical Decisions

      

        

          

            
🧩

            Sandbox Safety
          

          
1. Custom AST Virtual Sandbox

          
Statements are evaluated through an AST traversal engine that handles scope resolution, binary operators, and control signals (BreakSignal, ContinueSignal, ReturnSignal) without any eval() or server dependencies.

        


        

          

            
📸

            Time Travel
          

          
2. Deterministic State Snapshotting

          
At every statement, the interpreter takes deep-cloned snapshots of all active variables and call stack frames, enabling full time-travel debugging (rewind, step-forward, jump to step, breakpoints).

        


        

          

            
🔥

            Big-O Engine
          

          
3. Static Heatmap & Complexity Heuristics

          
Before execution, the AST walker pre-computes asymptotic time bounds (O(1) through O(2ⁿ)) and applies 6-tier visual gutter accents: 🟩 Green for O(1) branches, 🟦 Blue for O(log n) halving/binary search, 🟨 Yellow for O(n) loops, 🟪 Purple for O(n log n) sorting, 🟥 Red for O(n²) nested loops, and 🟪 Magenta for O(2ⁿ) recursive calls.

        


        

          

            
🔴

            Debugging
          

          
4. Non-Blocking Breakpoint Engine

          
Breakpoints are evaluated during AST step traversal. When an active breakpoint line is encountered, the execution loop cleanly yields and synchronizes the UI without freezing browser thread execution.

        


        

          

            
📦

            Memory Blocks
          

          
5. Visual Memory Array Blocks

          
Array allocations and index updates are rendered as dedicated visual memory cells, giving learners and engineers direct insight into index-based mutations and array pointer movements.

        


        

          

            
🔒

            Privacy
          

          
6. Local-First Client Privacy

          
All AST parsing, runtime execution, and history persistence run entirely client-side using LocalStorage and Web APIs. Zero code telemetry or private logic leaves the user's browser.
